# Team handbook (synthetic)

## Planning
Sprint plans are proposed by the planning assistant and approved by the project manager. No ticket or calendar event is created without approval.

## Fair load
"Keep the load fair" means the difference in planned hours between team members should be as small as the task durations allow. Fairness never overrides availability.

## Release work
Release notes describe the API and UI changes in the release, so they are written after the payment API integration is complete.
